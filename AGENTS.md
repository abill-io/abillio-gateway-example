# Project instructions

For work that builds, extends, reviews or debugs an Abillio Company API
integration, use the
[`abillio-integration` skill](.agents/skills/abillio-integration/SKILL.md).
Read it before planning or editing the integration, then read the supporting
references relevant to the task. This includes adapting the example to
another language or framework.

For appearance-only changes, use the UI file map and visual conventions in
`README.md`. Use the integration skill too when the change affects onboarding,
invoice/payment status, consent or other API behavior.

The canonical skill lives in `.agents/skills/abillio-integration/`.
`.claude/skills/abillio-integration` points to that directory; edit the
canonical files so both agents receive the same guidance.
